# Sphota Specification v1, Part 2: Canonical Space, Quantization and Semantics

```
Status: Frozen (s1)
```

## 1. Principle: freeze a space, not a model

The standard is the **frozen canonical space plus the frozen codebook**. The *anchor model*
is the reference instrument used to define the space; it is not the standard. Any embedding
model may produce conforming codes by mapping into the canonical space through a certified
adapter (Part 4).

## 2. The anchor (reference instrument)

| Field | v1 value |
|---|---|
| Model | `intfloat/multilingual-e5-small` (MIT), 384-d |
| Input | `"query: " + text` |
| Pooling | attention-masked mean over the last hidden state |
| Normalization | L2 |
| Reference implementation | `onnx/model.onnx` (fp32) in the model repository, max 512 tokens |

Implementations using another runtime (PyTorch, transformers.js) or another precision
(int8) are *variants*: they are certified like adapters (Part 5) against the reference.

## 3. Canonical transform

```
x  = anchor(text)                       # unit vector, R^384
y  = (x − μ) · W                         # R^D, D = 256 (s1)
```

`μ` and `W` are shipped in `space.npz`. `W` is the product of a PCA (to `P = 384`
directions) and a **meaning-LDA** projection: the top-`D` generalized eigenvectors of
`(S_total, S_within + reg)` where

* `S_total` is the covariance of a multilingual corpus (Wikipedia sample, FLORES-200 dev),
* `S_within` is the scatter of translations of the same sentence around their mean
  (FLORES-200 dev, 12 languages; Tatoeba pairs), shrunk toward isotropy (`reg = 0.05`),

scaled so that `vᵀ S_within v = 1`. Consequence: Euclidean distance in the canonical space is
measured in **translation-noise units**: one unit is the typical spread between translations
of the same sentence along that direction.

## 4. Quantization

The quantizer is **residual k-means** with `L = 4` levels and codebooks
`C_1 ∈ R^{4096×D}`, `C_2, C_3, C_4 ∈ R^{256×D}` (`codebooks.npz`).

```
r_0 = y
for l in 1..4:
    i_l = argmin_k ‖r_{l−1} − C_l[k]‖²     (ties → smallest k)
    r_l = r_{l−1} − C_l[i_l]
```

Computation SHOULD use float64 accumulation for distances. Implementations MUST produce the
same indices as the reference implementation (`sphota.space.quantize`) on the golden test
set (`tests/vectors/golden.json`) except for points whose top-2 distance gap at some level
is below `1e-4` (numerical ties), which conformance tests skip.

### 4.1 Stable mode (optional, non-default)

Stable mode replaces the argmin at each level with a deterministic majority vote:

```
Z = fixed N(0, I) samples, 32 × D, generated by numpy PCG64 seed 20261104
votes(k) = #{ s : argmin_{k' ∈ top16} ‖r + σ·Z_s − C_l[k']‖ = k }
i_l = argmax_k votes(k)    (ties → the nearest centroid)
```

`σ` (`noise_scale`) is in `calibration.json`. Codes produced in stable mode are valid
s1 codes; they differ from default-mode codes only for near-boundary inputs. Systems MUST
NOT mix modes within one index unless they accept that difference (the mode SHOULD be
recorded alongside stored codes).

## 5. Semantics

* **Region.** A prefix `p` of depth `d` denotes the set of canonical vectors whose first `d`
  indices equal `p`'s. Regions of depth `d+1` partition their parent region.
* **Point.** A prefix also denotes the point `Σ_{l≤d} C_l[i_l]` (its reconstruction), used for
  distances (Part 3).
* **Meaning claim.** Texts with the same code are *close in the canonical space*: they are
  about similar things. Codes are not definitions, labels are descriptive aids, and two texts
  with different codes may still be close (they may lie on either side of a boundary;
  Part 3 gives the tools to handle this).
* **Granularity guide (s1, measured on held-out data).** L1 ≈ topic area ("corporate
  leadership changes"), L2 ≈ sub-topic, L3/L4 ≈ near-paraphrase neighbourhoods. See
  `docs/benchmark.md` for agreement rates per level.
