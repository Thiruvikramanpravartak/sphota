# 30-day growth checklist

## Before day 0
- [ ] Repo public, README final, Atlas deployed (GitHub Pages + HF Space), PyPI published
- [ ] `pip install sphota` → quick start verified on fresh macOS, Windows, Linux
- [ ] Demo video (60 s) + 3 GIFs (cross-lingual compare, zoom, analyze report)
- [ ] Paper draft on arXiv (cs.CL, cross-list cs.IR), linked from README
- [ ] 10 friendly reviewers lined up for day-0 feedback (IR, multilingual NLP, data eng)

## Week 1: launch
- [ ] Day 0 (Tue/Wed, 8–9am PT): Show HN (launch/hacker-news.md); stay in thread all day
- [ ] Day 0: X/Twitter thread + LinkedIn post (launch/x-thread.md, launch/linkedin.md)
- [ ] Day 1: r/MachineLearning [P], r/LocalLLaMA, r/LanguageTechnology (launch/reddit.md)
- [ ] Day 2: HF Space featured request; post in HF Discord #i-made-this
- [ ] Day 3: write "What we got wrong" follow-up from feedback; triage issues within 24 h
- [ ] Label 15 `good first issue`s (new label languages, adapters, DB integrations)

## Week 2: integrations and proof
- [ ] PRs/plugins: LangChain community, LlamaIndex hub, Qdrant/Chroma cookbook entries
- [ ] Blog: "Never re-index again: migrating a 1M-doc index across embedding models"
- [ ] Certify 5 more popular open models; leaderboard announcement
- [ ] Indic NLP communities (AI4Bharat, Tamil/Hindi NLP groups): Hindi/Tamil label review drive

## Week 3: community and standard
- [ ] First RFC open publicly (e.g. "label languages policy" or "s2 full-scale build")
- [ ] Office hours / Discord channel; CONTRIBUTING walkthrough video
- [ ] Talk submissions: PyData, Berlin Buzzwords, FOSDEM (data/ML devrooms)

## Week 4: scale
- [ ] GPU `full`-scale build plan published (s2 candidate) with migration table preview
- [ ] Case study with one early adopter (analytics or support routing)
- [ ] Metrics review: stars, pip installs, Atlas visits, certified adapters, issues closed;
      decide next quarter's roadmap in public

## Metrics to watch
GitHub stars/forks, PyPI downloads (pypistats), Atlas unique visitors, HF Space likes,
number of certified adapters, external PRs, time-to-first-response on issues.
